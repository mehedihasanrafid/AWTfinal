# Practical React Lab Series

Three standalone React projects based on the supplied lab sheet.

## Projects

- `lab-01`: Components, props, PropTypes, and custom styling
- `lab-02`: Lab 01 plus state, effects, search, sorting, and favorites
- `lab-03`: Lab 02 plus Context API, theme switching, validated forms, removal, and localStorage

## Run any lab

```bash
cd lab-01
npm install
npm run dev
```

Replace `lab-01` with the lab you want to run.
